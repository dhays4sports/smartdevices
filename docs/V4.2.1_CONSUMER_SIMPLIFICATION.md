# SmartDevices v4.2.1 Consumer Simplification

## Outcome

The v4.2 carrier-intelligence engine is preserved while the public presentation is reduced to one decision, question, conclusion, or primary action per screen.

## Public flow

1. `/insurance` presents the currently supported carrier and a generic path for everyone else. It does not force search UI while only one carrier is published.
2. `/farmers` asks why the visitor came.
3. The visitor chooses the closest device category on a separate screen.
4. Four bounded questions establish jurisdiction, home context, capability and installation stage.
5. Results lead with one plain-language starting point, one plan action, one answer-review action and a short agent-confirmation checklist.
6. Product options appear before technical provenance. Evidence, capability distinctions, installation documentation and independent recommendations remain in collapsed detail sections.

## Preserved boundaries

- Farmers evidence remains separate from generic device facts.
- Consumer and professional assertions remain separate from carrier determinations.
- No device is represented as approved, certified, guaranteed eligible or universally required.
- California evidence is not applied outside California.
- Plan v1/v2/v3, SmartDevices Pro, evidence lifecycle, secure handoff and disabled-provider behavior are unchanged.
- Public deployment, live carrier/legal approval, hosted service activation, physical browser/assistive-technology review and representative field performance remain external.
