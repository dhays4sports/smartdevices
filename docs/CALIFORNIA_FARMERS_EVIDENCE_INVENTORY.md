- Water: public evidence supports a potential category involving detection and shutoff. A point sensor is not substituted for whole-home monitoring or automatic main-line shutoff. The California page currently supports a Moen Flo public-offer designation only while that carrier-controlled page remains current.
- Automatic gas shutoff: the Farmers page names the category. No public product-level Farmers qualification is inferred. California DSA listing and local installation/permitting are separate technical and safety checks.
- Fire alarm/security system/internal sprinklers: the Farmers page names broad protective-device categories. It does not state that every app notification, consumer alarm, monitoring plan, or certificate qualifies.
- Connected home: the Farmers page names remote monitoring and control. Product/system eligibility, interoperability, outage behavior, subscription, privacy, and account security remain separate.
- Requirements: the leak page says devices may be required in some locations/older-plumbing contexts. This does not create a universal Farmers requirement and does not prove a requirement for any user. A requirement appears only as the user's/professional's literal assertion unless authorized case evidence is later provided.
