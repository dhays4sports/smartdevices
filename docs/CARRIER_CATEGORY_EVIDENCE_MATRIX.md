# California carrier category/evidence matrix

Checked 2026-08-26. Public pilot scope: Farmers, California, Home. This matrix is internal governance documentation, not an eligibility table.

| Category | Governed public carrier state | Product state | Published experience | Confirmation boundary |
|---|---|---|---|---|
| Whole-home water | Public offer plus potential category while current sources remain active | Moen Flo named; current observed availability unavailable | Full scan, map, causal demo, fit, checklist, plan | Policy, property, product, installation, offer availability, documentation |
| Automatic gas shutoff | Potential category only | No product-level designation | Class-only guide | Valve type/listing, utility, jurisdiction, installer, inspection, carrier |
| Fire/security monitoring | Potential category only | Technical records do not by themselves establish eligibility | Class distinctions and independently labeled options | Signal type, monitoring, dispatch, subscription, certification, documentation |
| Connected home | Potential broad category only | No product-level carrier designation | Class-only dependencies/privacy/outage guide | Exact system, capability, integration currency, policy treatment |
| Editorial-only Home/Vehicle | No carrier designation | Independent catalog only | Small optional set or coherent zero-result state | Product facts and protection fit only |
| Unsupported carrier/state | Not verified | No carrier overlay | Generic SmartDevices guidance | Carrier/state-specific confirmation |

The deterministic matrix must suppress positive labels for draft, stale, conflicting, withdrawn, retired, restricted, out-of-scope, or unavailable governed evidence. Fewer than three options is an accepted outcome.
