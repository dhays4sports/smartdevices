# SmartDevices v4.2.2 Daily Utility Release

## Product outcome

SmartDevices now has one stable return pattern for customers and professionals:

1. Protect something, research a device, or check insurance guidance.
2. Create a small, explainable Smart Safety Plan.
3. Return through **My Plan** and reopen the exact local plan.
4. Recheck dated guidance when the plan matters again.

The homepage remains protection-first. Device research, insurance guidance, saved plans and agent tools are subordinate paths, not competing primary journeys.

## Daily-use contract

| User | Repeat job | Permanent entry |
|---|---|---|
| Customer | Start or repeat a protection check | `/#protection-entry` |
| Customer | Research reviewed devices | `/devices` |
| Customer | Understand applicable carrier guidance | `/insurance` |
| Customer | Reopen a plan stored on this device | `/my-plan` |
| Professional | Build or review client-ready guidance | `/pro` |

Plans remain private by default and stored locally. The local index is bounded to 20 plans and can discover existing local v1, v2 and v3 plan records. It is not a cloud backup, carrier determination, policy record or professional verification.

## Visual direction

- One dominant action per surface.
- Large, calm editorial typography.
- Generous spacing and soft depth instead of dense chrome.
- Deep teal and near-white surfaces with the existing lime signal used sparingly.
- Short, literal labels instead of feature-heavy marketing copy.
- Trust is shown through source dates, visible unknowns and explicit boundaries.
- Accessibility, clarity and action remain more important than decoration.

This is an Apple-like interaction standard, not imitation of Apple branding, trade dress or assets.
