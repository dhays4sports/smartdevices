# Sample California Farmers monitored-security Smart Safety Plan

Status: non-client sample; no PII; checked 2026-08-26.

## Stated context

The consumer selected “check possible discounts” and was unsure whether their current alarms have professional monitoring. No policy-specific requirement or eligibility determination is asserted.

## Potentially relevant public category

Farmers' public California homeowners-discount guidance names qualifying fire alarm and security protective-device categories. That category reference does not establish that an app-connected alarm, a particular product, or this consumer earns a discount.

## Priority map

1. Identify whether the need is fire signaling, burglary monitoring, or both.
2. Separate local sirens and phone alerts from central/professional monitoring and any dispatch protocol.
3. Confirm the monitoring provider, subscription, connectivity, backup power, testing, certification, and documentation.
4. Review privacy, account access, cameras, household consent, and outage behavior.
5. Ask Farmers to confirm policy applicability and accepted evidence.

## Options and decision considerations

| Area | Plan guidance |
|---|---|
| Solution classes | Local alarm, app/remote alert, central/professional monitoring, outside signaling, and dispatch connection are different capabilities. A connected consumer alarm is not automatically a qualifying monitored system. |
| Device options | This sample remains class-level because current governed evidence does not support a product-level Farmers qualification. Independent catalog options may be researched separately without a carrier designation. |
| Cost | Confirm equipment, installation, activation, permit/registration, recurring monitoring, cellular backup, cancellation, and replacement costs directly with providers. |
| Setup and compatibility | Confirm sensor/zone coverage, household access, Wi-Fi/cellular dependency, hub/ecosystem fit, backup power, audible signaling, monitoring protocol, and any professional installation/certification required. |
| Subscription and outages | Establish what functions continue during power, internet, cloud, or cellular failure and which alerts, storage, verification, dispatch, or support require a subscription. |
| Maintenance | Follow applicable alarm testing, battery/replacement, contact-list, permit, monitoring-certificate, and provider maintenance instructions. Life-safety alarms require applicable code and manufacturer placement/testing independent of this plan. |
| Privacy/security | Review camera/audio scope, household/visitor consent, administrator roles, account recovery, multi-factor authentication where offered, recording retention, law-enforcement sharing settings, and account closure. |
| Insurance/documentation | Ask Farmers or the licensed agent which exact capability/category, provider documentation, certificate, installation, subscription status, and renewal evidence apply to the specific California policy, if any. |

## Assumptions and literal state

Known: California and possible-discount intent were selected; current monitoring capability is unknown. Unknown: policy scope, alarm type, provider, listing/certification, dispatch relationship, subscription, installation, documentation, category applicability, eligibility, and savings. Recommendation state is `researching`; no selection, purchase, installation, evidence receipt, professional review, or carrier determination is recorded.
